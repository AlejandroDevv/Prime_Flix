# 🎬 Prime Flix

Aplicação web desenvolvida com React para consulta e exibição de filmes.

O projeto utiliza uma API para buscar informações sobre filmes e apresenta os resultados de forma organizada e intuitiva.

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- API de filmes
- CSS

  ## ✨ Funcionalidades

- 🎬 Listagem de filmes
- 🔎 Busca e consulta de filmes
- 📄 Visualização de informações dos filmes
- 🔄 Consumo de dados através de API
- 📱 Interface responsiva

  ## 🌐 Demonstração

🔗 [Acessar aplicação](https://prime-flix-theta.vercel.app/)

## ⚙️ Como executar o projeto

### Pré-requisitos

- Node.js instalado
- Git instalado

### Instalação

```bash
git clone https://github.com/AlejandroDevv/Prime_Flix.git
cd Prime_Flix
npm install
```

### Executar o projeto

```bash
npm start
```

**Após iniciar o servidor, acesse http://localhost:3000 no navegador.**
